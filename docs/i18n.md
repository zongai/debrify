# App language (i18n)

Debrify ships a lightweight localization layer under `lib/l10n/`.

## Supported UI languages

- English (`en`) — default fallback
- Chinese (`zh`)
- Japanese (`ja`)
- System — follow the device locale when it matches a supported language

## User setting

**Settings → Appearance → Language**

Preference is stored as `app_language` (`system` | `en` | `zh` | `ja`).

## Adding strings

1. Add the same key to every map in `lib/l10n/app_localizations.dart` (`en`, `zh`, `ja`).
2. Expose a getter on `AppLocalizations`.
3. Replace hardcoded UI text with `AppLocalizations.of(context).yourKey`.

Material / Cupertino framework strings are provided by `flutter_localizations`.

## Scope

Not every screen is translated yet. Media server (including Plex) settings and
the language picker are fully wired as the reference pattern. Prefer migrating
high-traffic surfaces next (Settings rows, Home, player chrome).
